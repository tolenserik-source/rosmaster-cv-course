# Первый час: получите свой первый результат

Цель: самостоятельно запустить программу, увидеть, как она преобразовала изображение, и объяснить результат. На этом этапе достаточно ноутбука; робот подключается после знакомства с данными.

**Работаете на нашем ROSMASTER `192.168.1.185`?** Откройте [«Запуск на нашем ROSMASTER» в первом уроке](lessons/01_intro.md#запуск-на-нашем-rosmaster). Там указаны вход `jetson`, готовая папка курса, команды запуска, перенос результатов на ноутбук и оформление отчёта. На общем роботе выполняйте этот маршрут с личной папкой результатов. Шаги ниже подходят для самостоятельной подготовки собственной копии курса.

## 1. Получите папку курса

Скачайте ZIP курса или выберите **Code → Download ZIP** в его репозитории GitHub. Распакуйте архив. Если название папки заканчивается на `-main`, для удобства переименуйте её в `rosmaster-cv-course`. Файлы `README.md`, `requirements-laptop.txt`, папки `data` и `rosmaster_cv` должны находиться рядом.

На ноутбуке откройте терминал в этой папке. На нашем роботе первый запуск выполняйте по разделу выше; перед остальными уроками создайте [личную копию курса](docs/SETUP_ROBOT.md#0-подключитесь-и-создайте-личную-копию). Там приведены команды и соответствие путей host/контейнера. Проверьте `pwd` и `ls data/scene.png` в том терминале, где запускаете Python.

## 2. Выберите окружение

**На роботе:** выполните проверку, не переустанавливая библиотеки:

```bash
python3 tools/doctor.py
```

Откройте `outputs/environment.json`. Должны импортироваться `numpy` и `cv2`. Наличие или отсутствие ROS фиксируется отдельно и не мешает первому уроку.

**На личном ноутбуке:** если OpenCV ещё нет, создайте новое окружение по разделу ноутбука в [SETUP_ROBOT](docs/SETUP_ROBOT.md). Сначала убедитесь, что версия Python находится в диапазоне 3.9–3.12. В активированном окружении команды `python` и `python3` могут называться по-разному; используйте его интерпретатор.

Если Python пока незнаком, прочитайте [короткий вводный материал](docs/PYTHON_MINIMUM.md). Для начала достаточно понимать переменную, функцию, список и координаты пикселя.

## 3. Выполните первый урок

В корне репозитория:

```bash
python3 -m rosmaster_cv.lesson01_intro --input data/scene.png --out outputs/01
```

Команда должна завершиться без traceback и создать файлы в `outputs/01`. Посмотрите исходное изображение и результат в оттенках серого. Полный список результатов и объяснение находятся в [уроке 9.1](lessons/01_intro.md).

Ответьте своими словами: сколько каналов в цветном изображении, почему OpenCV использует порядок BGR и почему `image[y, x]` сначала содержит координату строки?

## 4. Сделайте собственное изменение

Скопируйте свой PNG/JPG в `student_photos/` (папку можно создать). Используйте понятное имя латиницей, например `table.jpg`. Не меняйте учебный `data/scene.png`.

```bash
python3 -m rosmaster_cv.lesson01_intro --input student_photos/table.jpg --out outputs/01_own
```

Сравните ширину, высоту и результаты преобразования. Если фотография не читается, проверьте путь и формат файла в [разборе ошибок](docs/TROUBLESHOOTING.md).

## 5. Откройте блокнот, если вам удобнее Jupyter

Блокноты находятся в `notebooks/`. Начните с `01_intro.ipynb`. Его первые ячейки определяют папку курса и используют текущий Python. Можно запускать по одной ячейке сверху вниз. Полные инструкции продублированы внутри.

На роботе найдите действующий Jupyter или запустите свой сервер и SSH-туннель по [готовым командам](docs/SETUP_ROBOT.md#5-работа-через-ssh-vnc-и-jupyter). На ноутбуке в отдельном окружении можно установить `jupyterlab` и запустить `python -m jupyterlab`. Все уроки также выполняются из терминала. Не публикуйте пароль или token Jupyter в отчёте.

## 6. Подготовьтесь к камере

Сначала проверьте получение кадров на комплектном видео:

```bash
python3 tools/capture.py --source data/demo.avi --frames 30 --save-every 10 --out outputs/capture_video
```

Для настоящей камеры самостоятельно определите устройство, проверьте формат и занятость по [проверке камеры](docs/SETUP_ROBOT.md#4-проверьте-настоящую-камеру). На host нашего стенда после этой проверки используйте `/dev/camera_usb`:

```bash
timeout 15s python3 tools/capture.py --source /dev/camera_usb --frames 5 --save-every 1 --out outputs/capture_camera
```

Если RGB уже публикуется драйвером ROS, используйте [урок 9.8](lessons/08_ros_image.md). Два процесса не должны одновременно захватывать одно устройство камеры. Depth-поток не нужно выдавать за обычное цветное видео.

## 7. Сохраните первый отчёт

Скопируйте [шаблон отчёта](templates/REPORT.md) в `reports/01_Фамилия.md`. Укажите окружение, точные команды, приложите исходное изображение и свой результат, ответьте на три вопроса. Отметьте урок в [листе прогресса](templates/PROGRESS.md), затем переходите к [геометрическим преобразованиям](lessons/02_geometry.md).

**Критерий первого часа:** вы можете повторно получить результат из исходного файла и объяснить, что изменилось. Одного скриншота запущенного терминала недостаточно.
