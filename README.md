# Компьютерное зрение с нуля на ROSMASTER X3 Plus

**Самостоятельный практикум на русском языке: от первого изображения до потока ROS, AR-маркеров и MediaPipe.**

Курс подготовлен для студентов направления «Робототехнические системы», модуль «Компьютерное зрение», КазНУ им. аль-Фараби. Преподаватель: **Серик Толенов**. Версия 1.0, 17 октября 2026 года.

Последовательность соответствует темам **9.1–9.11 OpenCV courses** из [материалов Yahboom](https://www.yahboom.net/study/ROSMASTER-X3-PLUS/). Внутри — собственные учебные примеры, инструкции, ожидаемые результаты, эксперименты и критерии завершения. Математика вводится на уровне, необходимом для каждого опыта.

## Начать здесь

1. Откройте [START_HERE.md](START_HERE.md) и выполните первый час практикума.
2. Проверьте [окружение робота или ноутбука](docs/SETUP_ROBOT.md). Для настоящего стенда преподаватель заполняет [паспорт](templates/ROBOT_PASSPORT.md).
3. Проходите темы таблицы сверху вниз. Сначала получите результат на учебных данных, затем повторите эксперимент со своими кадрами.
4. По каждой теме сдайте [отчёт](templates/REPORT.md) и отметьте [прогресс](templates/PROGRESS.md).

**Единая книга:** [STUDENT_GUIDE.html](STUDENT_GUIDE.html) — весь текст курса в одном файле, открывается обычным браузером без интернета. Для выполнения программ нужна папка репозитория. **Блокноты:** [notebooks](notebooks/) — полные инструкции с исполняемыми ячейками. Аппаратные ячейки выключены по умолчанию.

## Первый запуск

Откройте терминал **в корне распакованного репозитория**. На заводском роботе сначала используйте уже установленные библиотеки:

```bash
python3 tools/doctor.py
python3 -m rosmaster_cv.lesson01_intro --input data/scene.png --out outputs/01
```

Если `cv2` отсутствует на ноутбуке, выполните маршрут нового виртуального окружения из [SETUP_ROBOT](docs/SETUP_ROBOT.md). Файл `requirements-laptop.txt` предназначен для нового окружения ноутбука с Python 3.9–3.12. Не устанавливайте его поверх заводского OpenCV робота.

Программы сохраняют результаты в `outputs/`, поэтому ими можно пользоваться через SSH без графического экрана. Откройте созданные PNG на ноутбуке, в Jupyter или в файловом менеджере VNC.

## Как понимать разные комплектации ROSMASTER

Фактический образ и окружение важнее названия платы. На некоторых комплектациях ROS1 запускается внутри заводского Docker-контейнера. ROS Melodic обычно использует Python 2 для ROS-пакетов, а учебные программы написаны на Python 3: доступность `rospy` и `cv_bridge` нужно проверить в выбранном интерпретаторе. Для такого случая в уроках приведён законченный заводской маршрут. ROS2-команды не являются заменой ROS1-команд из этого раздела. См. [настройку](docs/SETUP_ROBOT.md) и [первоисточники](docs/SOURCES.md).

Работа с изображением на ноутбуке готовит к опыту на роботе. Для зачёта аппаратных уроков нужны настоящие данные стенда: ручная накладка не считается распознаванием ALVAR, синтетический скан не считается измерением лидара.

## Где что находится

| Папка или файл | Назначение |
|---|---|
| `lessons/` | Пошаговые главы 01–11 |
| `rosmaster_cv/` | Исполняемые модули Python; запуск через `python3 -m` |
| `notebooks/` | Те же главы в Jupyter |
| `data/` | Синтетические изображения, QR и короткое видео |
