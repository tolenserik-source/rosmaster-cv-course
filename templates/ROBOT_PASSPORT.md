## Откуда брать значения

Команды выполняйте в среде, которую записываете: host и контейнер имеют разные версии. Полный порядок входа и запуска — в [настройке](../docs/SETUP_ROBOT.md).

| Поля паспорта | Самостоятельная проверка |
|---|---|
| ОС, архитектура, Python и библиотеки | `cat /etc/os-release`, `uname -m`, `python3 tools/doctor.py`; прочитайте `outputs/environment.json` |
| Папка и контейнер | `pwd`, `docker ps -a`, `docker inspect --format '{{json .Mounts}}' busy_yalow` на host |
| ROS и пакеты | `printenv ROS_VERSION ROS_DISTRO`, импорт `rospy`/`cv_bridge`, `rospack find yahboomcar_visual` внутри нужной ROS1-среды |
| Камера и её занятость | `v4l2-ctl --list-devices`, `fuser -v /dev/camera_usb`, пять сохранённых и просмотренных кадров |
| Топики | `rostopic find sensor_msgs/Image`, аналогично для `CameraInfo`, `LaserScan`, `PointCloud2`; затем `rostopic type` и `rostopic hz` с найденным именем |
| Калибровка и размеры | Собственные измерения клетки/маркера линейкой, реальная калибровка урока 6 и её JSON; чужая матрица камеры не подставляется |
| Глубина и единицы | Документация установленного драйвера и сравнение с известным расстоянием; отсутствие данных отмечается явно |
| Доступ к результатам | Скачайте PNG/JSON командой `scp` из настройки, откройте и проверьте содержимое |

Сохраняйте ссылки на файлы своего опыта рядом со значениями. Установленный пакет и существующий топик без сообщений ещё не подтверждают работу датчика.

## Самопроверка

- [ ] `tools/doctor.py` выполнен в нужном окружении.
- [ ] Урок 9.1 создал PNG и JSON.
- [ ] Получены реальные RGB-кадры, они открываются на ноутбуке.
- [ ] Для ROS-пути проверены master, топик, тип и частота.
- [ ] Depth сохраняет исходные значения, единицы подтверждены.
- [ ] Узел 9.9 публикует маску и завершает работу по времени.
- [ ] Реальная калибровка и AR проверены на выбранном разрешении.
- [ ] Настоящий ALVAR распознан с правильным размером маркера.
- [ ] Реальные LiDAR/PointCloud данные проверены.
- [ ] MediaPipe обнаруживает человека/руку на собственном контрольном кадре.

Поле, которое пока не проверено, не закрывается результатом синтетического примера. Занятия по уже проверенным базовым темам можно проводить независимо.
