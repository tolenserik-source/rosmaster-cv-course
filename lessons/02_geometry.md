# 02. Размер, вырезание, сдвиг и перспектива

**Тема Yahboom:** 9.2 Geometric transformation. **Время:** 60–90 минут.

## Цель и место выполнения

Научитесь менять геометрию изображения и объяснять, как меняются координаты объектов. Основная часть соответствует масштабированию, вырезанию, переносу и отражению из раздела производителя. Поворот, аффинное преобразование и выпрямление плоскости добавлены как учебное расширение.

Работайте на ноутбуке или компьютере неподвижного ROSMASTER, в корне курса. Достаточно окружения первого урока; камера и ROS пока не нужны. Результаты сохраняются в файлы, поэтому команду можно выполнить и через SSH.

## Пять понятий

**Масштабирование** меняет количество пикселей. Коэффициент `0.5` уменьшает обе стороны вдвое: изображение 800×600 становится 400×300. При уменьшении программа объединяет информацию соседних пикселей. Обратное увеличение не возвращает потерянные мелкие детали.

**Вырезание, или crop**, выбирает прямоугольную область. Четыре числа `X Y W H` задают её левый верхний угол, ширину и высоту. Выбранная область получает собственное начало координат: её прежняя точка `(X, Y)` становится `(0, 0)`.

**Сдвиг и отражение** меняют положение содержимого. Положительный `DX` передвигает изображение вправо, положительный `DY` — вниз. Горизонтальное отражение переставляет левую и правую стороны; это важно помнить при интерпретации картинки с камеры.

**Аффинное преобразование** включает линейное изменение координат и перенос. В примере добавлен небольшой наклон, или сдвиг строк относительно друг друга. Прямые сохраняются прямыми, параллельные направления остаются параллельными.

**Перспективное преобразование** сопоставляет четыре угла плоского объекта с углами нового прямоугольника. Оно помогает представить наклонённую табличку как вид спереди. Это работа с одной плоскостью; объекты вне неё могут выглядеть искажёнными. Само преобразование не определяет расстояние до объекта в метрах.

## Практика: восемь шагов

1. Убедитесь, что после первого урока существует `data/scene.png`. Посмотрите параметры:

   ```bash
   python3 -m rosmaster_cv.lesson02_geometry --help
   ```

2. Запустите стандартный набор преобразований:

   ```bash
   python3 -m rosmaster_cv.lesson02_geometry --input data/scene.png --out outputs/02
   ```

   Откройте `report.json`. Найдите размеры каждого результата. Стандартная центральная вырезка имеет размер 400×300.

3. Откройте `resized.png` и `cropped.png`. У них одинаковые размеры при настройках по умолчанию, но различное содержимое. В отчёте объясните происхождение этого различия.

4. Получите собственную вырезку вокруг красного круга:

   ```bash
   python3 -m rosmaster_cv.lesson02_geometry --crop 80 120 160 160 --scale 0.25 --out outputs/02_crop
   ```

   Проверьте центр круга в вырезке. Вычислите его новые координаты вручную из координат первого урока.

5. Измените перенос и отражение:

   ```bash
   python3 -m rosmaster_cv.lesson02_geometry --translate 100 50 --flip 0 --out outputs/02_shift
   ```

   `translated.png` показывает перенос, `flipped.png` — вертикальное отражение. Это отдельные преобразования исходника: программа не применяет их последовательно друг за другом.

6. Сравните углы поворота `25` и `-25`:

   ```bash
   python3 -m rosmaster_cv.lesson02_geometry --angle -25 --out outputs/02_rotation
   ```

   Поворот выполняется вокруг центра; размер холста сохраняется. Чёрные участки появляются там, где нет исходных данных. Часть изображения может выйти за границу холста.

7. Выпрямите специально подготовленную плоскость:

   ```bash
   python3 -m rosmaster_cv.lesson02_geometry --input data/portrait_plane.png --out outputs/02_plane
   ```

   Это геометрическая таблица, несмотря на слово `portrait` в имени. Сначала откройте `source_corners.png`: числа 1–4 обозначают верхний левый, верхний правый, нижний правый и нижний левый углы. Затем откройте `perspective.png`, ожидаемый размер — 400×300.

8. Измените размер результата плоскости и сравните пропорции:

   ```bash
   python3 -m rosmaster_cv.lesson02_geometry --input data/portrait_plane.png --warp-size 400 400 --out outputs/02_square
   ```

   Объясните, почему квадратный результат растягивает содержимое по сравнению с исходными пропорциями таблицы.

## Ожидаемые файлы

Каждая папка запуска содержит `resized.png`, `cropped.png`, `translated.png`, `flipped.png`, `rotated.png`, `affine.png`, `source_corners.png`, `perspective.png` и `report.json`. В отчёте сохранены параметры, матрицы и размеры результатов. На обычной сцене стандартные углы перспективы выбирают произвольную область; осмысленное выпрямление предусмотрено для `portrait_plane.png`.

## Самостоятельное изменение

Сфотографируйте прямоугольный лист, положенный под углом, и сохраните его как `data/my_plane.jpg`. Оцените четыре угла. Делите каждое `x` на `width−1`, каждое `y` на `height−1`; получатся числа от 0 до 1. Передайте их через `--src` в порядке TL, TR, BR, BL. Например, стандартные координаты учебной плоскости: `--src 0.18 0.16 0.80 0.22 0.90 0.86 0.12 0.78`. Для собственного фото значения нужно измерить заново. Сравните результат двух наборов углов.

## Три вопроса

1. Во сколько раз уменьшится количество пикселей при `--scale 0.5`?
2. Как изменятся координаты точки `(160, 200)` после вырезки `80 120 160 160`?
3. Почему четыре угла плоскости нужно передавать в согласованном порядке?

## Что сдать и ошибки

Сдайте пару resize/crop, результаты сдвига и отражения, фото собственной плоскости с четырьмя отмеченными углами, её выпрямленный вариант и отчёты. Добавьте расчёт координат и короткое объяснение искажений.

**Вырезка вне кадра:** уменьшите ширину/высоту или проверьте левый верхний угол. **Неверные углы плоскости:** ориентируйтесь на `source_corners.png`; порядок с пересекающимися рёбрами отклоняется программой.
